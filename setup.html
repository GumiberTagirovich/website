Установка и настройка

Инструкция для Ubuntu 22.04. Команды выполняются от имени пользователя с правами sudo.

Шаг 1. Установка Nginx

Команды установки 
sudo apt update
sudo apt install nginx -y
sudo systemctl enable --now nginx
sudo systemctl status nginx

После этого откройте в браузере IP сервера — появится страница-заглушка Nginx.

Шаг 2. Виртуальный хост

Создание конфигурации сайта 
sudo mkdir -p /var/www/example.com/html
sudo chown -R $USER:$USER /var/www/example.com
sudo nano /etc/nginx/sites-available/example.com

Содержимое файла:

server {
    listen 80;
    server_name example.com;
    root /var/www/example.com/html;
    index index.html;

    location / {
        try_files $uri $uri/ =404;
    }
}

Включаем сайт и перезагружаем сервер:

sudo ln -s /etc/nginx/sites-available/example.com /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx

Шаг 3. Apache

Установка Apache 
sudo apt install apache2 -y
sudo systemctl enable --now apache2
Если Nginx уже занял порт 80, сначала остановите его: sudo systemctl stop nginx.

Шаг 4. PHP

PHP-FPM для Nginx 
sudo apt install php8.2-fpm -y

В конфиге сайта добавить:

location ~ \.php$ {
    include        fastcgi_params;
    fastcgi_pass   unix:/run/php/php8.2-fpm.sock;
    fastcgi_param  SCRIPT_FILENAME $document_root$fastcgi_script_name;
}
PHP для Apache 
sudo apt install libapache2-mod-php8.2 -y
sudo a2enmod php8.2
sudo systemctl restart apache2
