Языки программирования на сервере

Сам веб-сервер умеет отдавать только готовые файлы. Чтобы страница собиралась на лету (с учётом базы данных и пользователя), нужен код на языке программирования. Сервер передаёт запрос приложению, а потом возвращает ответ клиенту.

Как сервер связан с языком

  • CGI — старый способ, новый процесс под каждый запрос;
  • FastCGI — постоянные процессы-обработчики;
  • Встроенные модули — например, mod_php в Apache;
  • Reverse proxy — запрос передаётся приложению по HTTP.

Видео

Небольшая лекция о том, как работают веб-серверы.

Языки и способы подключения

Таблица 1. Языки и обработчики
Язык Обработчик Связь с Nginx
PHP PHP-FPM FastCGI через сокет
Python Gunicorn / uWSGI Reverse proxy
Node.js Сам Node Reverse proxy
Ruby Puma / Unicorn Reverse proxy
Java Tomcat Reverse proxy

Пример: PHP через FastCGI

location ~ \.php$ {
    include        fastcgi_params;
    fastcgi_pass   unix:/run/php/php8.2-fpm.sock;
    fastcgi_param  SCRIPT_FILENAME $document_root$fastcgi_script_name;
}

Пример: Python через прокси

# запуск приложения
gunicorn --workers 3 --bind 127.0.0.1:8000 myapp.wsgi:application

# конфиг Nginx
location / {
    proxy_pass http://127.0.0.1:8000;
    proxy_set_header Host $host;
}
В обоих случаях сервер не выполняет код сам — он передаёт запрос обработчику и возвращает его ответ.
